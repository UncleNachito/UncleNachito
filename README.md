## 📊 Featured Project

### Anomaly Detection in Electoral Polling Stations (Thesis)
A Python pipeline to identify statistically anomalous patterns in Chilean electoral results, using Random Forest models and SHAP-based feature importance to interpret why a given polling station is flagged as an outlier.

- Processing and cleaning historical electoral data (multiple elections, 2013–2022)
- Comparison of different weighting schemes and ML models
- Model interpretability using SHAP to identify the most influential variables
